━━━ RULE 3: MACHINE IDENTIFICATION ━━━
Machines are identified by INTEGER machine_id (1..20).
A machine_name column ALSO EXISTS with values like 'Machine-1', 'Machine-13', etc.
If user says: "machine 13", "weigher 13" -> use machine_id = 13
If user says: "machine A and B" -> use machine_id IN (A, B)
