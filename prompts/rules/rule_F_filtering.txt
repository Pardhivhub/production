RULE F — FILTERING: DATES, ORDER BY, GRAMMAGE, SHIFTS, TEXT SEARCH

— Relative Date Ranges —
- "last 7 days" / "past week" → start_time >= CURRENT_DATE - INTERVAL '7 days'
- "this week" → start_time >= date_trunc('week', CURRENT_DATE)
- "May 2025" → EXTRACT(MONTH FROM start_time) = 5 AND EXTRACT(YEAR FROM start_time) = 2025
- "between [A] and [B]" → start_time >= 'A' AND start_time <= 'B'
- Wastage date column is production_start_time, not start_time.

— ORDER BY Direction —
- "highest", "most", "maximum", "top", "best" → ORDER BY [metric] DESC
- "lowest", "least", "minimum", "bottom" → ORDER BY [metric] ASC
- "highest availability" = LOWEST downtime → ORDER BY SUM(downtime_mins) ASC
- "lowest availability" = HIGHEST downtime → ORDER BY SUM(downtime_mins) DESC

— Grammage Format —
grammage is NUMERIC. Never add a 'g' suffix.
If user says "10.5g" or "43 grams" → use: WHERE grammage = 10.5
Common values: 10, 10.5, 20, 25, 26, 43 — pass through the numeric value from user query.
grammage exists in oee_details_data, ega_details_data, and wastage_records independently.

— Shift Filtering —
Shift boundaries:
  - Shift 1: 06:00 to 14:00
  - Shift 2: 14:00 to 22:00
  - Shift 3: 22:00 to 06:00 (next day)

For wastage_records → filter on the shift column: WHERE shift IN ('Shift 1', '1', 'A')
For oee_details_data / ega_details_data / production_speed_details_data → filter on start_time::time:
  - Shift 1: start_time::time >= '06:00' AND start_time::time < '14:00'
  - Shift 2: start_time::time >= '14:00' AND start_time::time < '22:00'
  - Shift 3: start_time::time >= '22:00' OR start_time::time < '06:00'

— Text Filtering —
When filtering on string names like line_name, machine_name, or plant_name, ALWAYS use ILIKE '%partial_name%' instead of exact = matching.
Example: WHERE l.line_name ILIKE '%Line 1%'
