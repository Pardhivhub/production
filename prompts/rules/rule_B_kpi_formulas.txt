RULE B — KPI FORMULAS (OEE, EGA, AVAILABILITY, QUALITY, PERFORMANCE)

TABLE: itciot.oee_details_data
TABLE: itciot.ega_details_data

— EGA Percent —
NEVER use AVG(ega_percent). Always re-derive from raw weights:
((SUM(t_weight) - SUM(theoretical_pack_weight)) / NULLIF(SUM(t_weight), 0)) * 100 AS ega_percent

— Availability Percent —
Each row = 60 scheduled minutes. Formula:
((SUM(1) * 60 - SUM(downtime_mins)) / NULLIF(SUM(1) * 60, 0)) * 100 AS availability_percent
Do NOT use SUM(run_duration) in the denominator for Availability.

— Quality Percent —
MUST incorporate BOTH failed_bags AND overlimit_count. Never use good_bags / (good_bags + failed_bags).
CASE WHEN SUM(good_bags) = 0 THEN 0
     ELSE (100 - ((SUM(overlimit_count) + SUM(failed_bags)) / NULLIF(SUM(good_bags), 0)) * 100)
END AS quality_percent

— Performance Percent —
target_speed is in bags/hour. Multiply actual bags/minute rate by 60:
((SUM(good_bags) / NULLIF((SUM(1)*60 - SUM(downtime_mins)), 0)) * 60) / NULLIF(AVG(target_speed), 0) * 100 AS performance_percent

— OEE Percent (3-component formula) —
There is NO pre-calculated oee column. Derive using:
(
  ((SUM(good_bags) / NULLIF((SUM(1)*60 - SUM(downtime_mins)), 0)) * 60 / NULLIF(AVG(target_speed), 0) * 100)
  * ((SUM(1)*60 - SUM(downtime_mins)) / NULLIF(SUM(1)*60, 0) * 100)
  * (CASE WHEN SUM(good_bags)=0 THEN 0
     ELSE (100 - ((SUM(overlimit_count)+SUM(failed_bags)) / NULLIF(SUM(good_bags),0)) * 100)
     END)
) / 10000 AS oee_percent

— Downtime —
SUM(downtime_mins) AS total_downtime_mins

— Total Production kg —
SUM(COALESCE(good_bags, 0) * COALESCE(grammage, 0)) / 1000 AS total_production_kg
