Example 1 — Machine downtime ranking on a date:
Q: "Which machine had the highest downtime on YYYY-MM-DD?"
SQL: SELECT machine_id, machine_name, SUM(downtime_mins) AS total_downtime FROM oee_details_data WHERE start_time::date = 'YYYY-MM-DD' GROUP BY machine_id, machine_name ORDER BY total_downtime DESC LIMIT 1

Example 2 — Total wastage by plant (JOIN):
Q: "Total wastage in Plant Name?"
SQL: SELECT SUM(w.wastage_kg) AS total_wastage FROM wastage_records w JOIN gmiiot_plants p ON w.plant_id = p.plant_id WHERE p.plant_name ILIKE '%Plant Name%'

Example 3 — Top N with metadata names (JOIN):
Q: "Top 3 machines by failed bags on YYYY-MM-DD, show actual machine names."
SQL: SELECT m.machine_name, SUM(o.failed_bags) AS total_failed_bags FROM oee_details_data o JOIN machines m ON o.machine_id = m.id WHERE o.start_time::date = 'YYYY-MM-DD' GROUP BY m.machine_name ORDER BY total_failed_bags DESC LIMIT 3

Example 4 — Compare two specific machines:
Q: "Compare failed bags and downtime for machine A and machine B on YYYY-MM-DD."
SQL: SELECT machine_id, machine_name, SUM(failed_bags) AS total_failed_bags, SUM(downtime_mins) AS total_downtime FROM oee_details_data WHERE start_time::date = 'YYYY-MM-DD' AND machine_id IN (A, B) GROUP BY machine_id, machine_name ORDER BY machine_id

Example 5 — Best line by wastage inside a plant (3-table JOIN):
Q: "Which line in Plant Name had highest wastage?"
SQL: SELECT l.line_name, SUM(w.wastage_kg) AS total_wastage FROM wastage_records w JOIN gmiiot_lines l ON w.line_id = l.id JOIN gmiiot_plants p ON w.plant_id = p.plant_id WHERE p.plant_name ILIKE '%Plant Name%' GROUP BY l.line_name ORDER BY total_wastage DESC LIMIT 1

Example 6 — Grouping by a custom entity (e.g. grammage or shift):
Q: "What is the average EGA percent for each grammage size?"
SQL: SELECT grammage, AVG(ega_percent) AS avg_ega FROM ega_details_data GROUP BY grammage ORDER BY avg_ega DESC

Example 7 — Array Unnesting for Production Speed:
Q: "What was the average production speed for Machine 1 on YYYY-MM-DD?"
SQL: SELECT AVG(CAST(val AS NUMERIC)) AS avg_speed FROM (SELECT jsonb_array_elements_text(production_speed_bpm) AS val FROM production_speed_details_data WHERE machine_id = 1 AND start_time::date = 'YYYY-MM-DD') sub

Example 8 — Side-by-side line comparison using ILIKE:
Q: "Total wastage for Line 1-Plant 1 versus Line 2-Plant 1."
SQL: SELECT l.line_name, SUM(w.wastage_kg) AS total_wastage FROM wastage_records w JOIN gmiiot_lines l ON w.line_id = l.id WHERE l.line_name ILIKE '%Line 1%' OR l.line_name ILIKE '%Line 2%' GROUP BY l.line_name ORDER BY l.line_name

Example 9 — Safely calculating derived percentages (e.g. Quality):
Q: "What is the quality percentage for all machines?"
SQL: SELECT machine_id, machine_name, COALESCE((SUM(good_bags) * 100.0) / NULLIF(SUM(good_bags) + SUM(failed_bags), 0), 0) AS quality_percentage FROM oee_details_data GROUP BY machine_id, machine_name ORDER BY quality_percentage DESC
